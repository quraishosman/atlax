# ADR-024: Telegram-Selected Single-Terminal MT5 Account Target

**Status:** Accepted  
**Date:** 2026-09-22  
**Owners:** ATLAX Engineering

## Decision

ATLAX provides an administrator-only Telegram **Trading Accounts** menu for
selecting a named MT5 account target on one local MT5 terminal. The registry
persists only a display label, MT5 login, exact broker server, timestamp, and
actor. It never stores a password or other broker secret.

Selecting a target ends the scanner's current MT5 connection. ATLAX then
attaches only to an already authenticated terminal session whose login and
server exactly match the selected target. It does not call `mt5.initialize`
with a password for a Telegram-selected target. An unavailable, mismatched, or
changed terminal identity prevents scanning and execution from resuming.

The Telegram account selector is independent from the Prop-Firm account-mode
switch defined by ADR-023. It selects the expected terminal identity; it does
not bind a Prop-Firm profile or alter risk policy.

## Rationale

Operators need to switch between several trading accounts without editing
YAML or environment files. Telegram is suitable for selecting a non-secret
identity, but is not a credential vault: its messages, chat history, backups,
and bot integration boundary must not carry live broker passwords.

MT5 already owns its authenticated session and password handling. Requiring a
matching terminal session prevents ATLAX from logging in to an unintended
account and makes a direct account change in MT5 fail closed.

## Consequences

- Account labels, logins, and servers survive restart as runtime state.
- The account wizard asks for label, login, and server only; it rejects any
  credential collection flow.
- Telegram controls remain available while MT5 authentication is failing, so
  an operator can select a different target during recovery.
- A selected target disables the generic `ATLAX_MT5_PASSWORD` fallback for
  that connection attempt, avoiding a stale password being submitted to the
  wrong account.
- The first account saved becomes selected; additional accounts are saved
  without changing the active target until the administrator explicitly
  selects one.
- One scanner and one MT5 terminal are supported. Multiple simultaneous MT5
  terminals remain out of scope.
