# ADR-013: H1 Momentum as Soft Confidence Context

Status: APPROVED  
Date: 2026-08-14  
Decision owner: Project Lead

## Context

The project lead observed that M5 and M15 CRT reversals often perform poorly
when they oppose the direction of one or more completed H1 candles. The desired
behavior is to express that context as lower confidence rather than suppressing
the setup. A single completed H1 candle establishes a small bias; two or more
consecutive candles provide stronger evidence. Sideways conditions must also
reduce confidence after their deterministic thresholds are approved.

The current confidence engine is a documented weighted model. Exact momentum
adjustments and sideways thresholds have not been approved, so they must not be
invented in live scoring.

## Decision

Implement a closed-candle H1 momentum evaluator for configured H1 -> M5 and
H1 -> M15 relationships. Store its result in candidate metadata and record a
counterfactual proposed score in shadow mode. Do not change detector rules,
strategy eligibility, nested routing, risk, or automatic execution in the
shadow phase.

At Telegram delivery, an explicit subscriber minimum confidence is evaluated
even when the event is below the profile default. Profile-default subscribers
continue to use the profile minimum. All existing subscription, style, pair,
ATR, and key-level-only gates remain active.

Promotion of the momentum adjustment requires a follow-up approval that defines
the exact aligned bonus, run-length bonus, opposing penalty, sideways penalty,
unknown behavior, and sideways measurement formula.

## Proposed Numeric Values (Phase 4 Promotion)

Based on shadow data analysis, the following configuration is proposed to be promoted to live:

```yaml
confidence:
  htf_momentum:
    enabled: true
    shadow_mode: false               # promote from shadow
    aligned_adjustment: +5           # bonus for aligned H1 momentum
    opposing_adjustment: -10         # penalty for opposing H1 momentum
    run_bonus_per_extra_candle: +3   # bonus per extra consecutive aligned candle
    max_run_bonus: +6                # cap on run bonus
    sideways_adjustment: 0           # no change for sideways (until defined)
    unknown_adjustment: 0            # no change for unknown data
```

## Consequences

Positive:

- H1 context becomes visible and testable without look-ahead.
- Opposing candidates remain available to subscribers who intentionally choose a
  lower threshold.
- The Google Sheets feedback and Signal Passport records can be segmented by
  H1 bias and run length before promotion.

Tradeoffs:

- Shadow telemetry adds a second score for analysis.
- A later approval is required before the proposed score affects live routing.
- The Alert Engine now distinguishes admin/profile gating from explicit
  subscriber threshold evaluation.

## Rejection / Rollback

Set `confidence.htf_momentum.enabled: false` or keep `shadow_mode: true` to
restore the pre-promotion live score. No historical candidate data is deleted.
