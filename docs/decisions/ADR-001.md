# ADR-001: TradingView Detection And MT5 Execution Boundary

Status: Accepted  
Date: 2026-07-14

## Context

ATLAX supports TradingView and MetaTrader 5, but each platform has different strengths and risks.

## Decision

TradingView is used for detector-side detection, visualization, and alert event generation.

MetaTrader 5 is used for execution, risk, trade management, and journal integration.

Any detector score or classification emitted by TradingView is detector metadata only. Final confidence scoring belongs to the documented ATLAX Confidence Engine.

## Consequences

- TradingView never executes trades.
- MT5 never performs complex market analysis.
- TradingView detector metadata must not bypass the Strategy Engine, Confidence Engine, Risk Engine, or approval flow.
- Execution requests must pass through documented ATLAX services.
- Platform boundaries must be enforced in code and tests.
