# ADR-002: Detector Independence

Status: Accepted  
Date: 2026-07-14

## Context

ATLAX must support CRT first and future strategies later without architectural rewrites.

## Decision

Every detector is independent.

Detectors do not know about each other.

The Strategy Engine is the integration point.

## Consequences

- Detectors return structured observations only.
- Detectors never return `BUY` or `SELL`.
- New detectors can be added without changing existing detectors.
- Strategy behavior remains explicit and testable.
