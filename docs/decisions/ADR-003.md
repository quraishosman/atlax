# ADR-003: AI Advisory Access Through Controlled Interfaces

Status: Accepted  
Date: 2026-07-14

## Context

AI can help analyze performance and explain data, but direct AI access to internal systems would weaken security and determinism.

## Decision

AI is advisory only and must access ATLAX data through controlled, audited, least-privilege interfaces such as the MCP gateway defined in `docs/16_SECURITY.md`.

## Consequences

- AI cannot detect CRTs.
- AI cannot define trading rules.
- AI cannot execute trades.
- AI cannot modify configuration without approval.
- AI cannot access raw databases, broker credentials, filesystems, or raw SQL.
- Every approved AI data request must be validated, sanitized, rate-limited, and audited.
