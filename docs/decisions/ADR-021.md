# ADR-021: Closed-Candle Momentum Protection Shadow Observer

Status: Accepted for shadow implementation; live action not approved  
Date: 2026-09-19  
Owners: ATLAX Engineering

## Context

A profitable position can lose directional momentum before it reaches a
configured target. Tick-only decisions are too noisy for a trade-management
rule, so ATLAX needs a reproducible observation based on completed candles.

## Decision

Phase 3 observes the configured source timeframe from the scanner's existing
closed-candle feed. A BUY requires the configured number of consecutive bearish
closed candles; a SELL requires the same number of bullish closed candles.
Neutral, forming, missing, or insufficient candles do not qualify.

The observer also requires the configured MFE activation, maximum giveback, and
minimum current-profit R floor. It records `momentum_exit_would_apply` once per
source candle, including the counterfactual protective action and lock level.
It does not modify stops or close positions. The repository configuration
enables the shadow collection observer while keeping `momentum_shadow_mode`
true. This does not authorize a live action.

## Consequences

- No additional MT5 candle request is needed when the source timeframe is
  already configured for scanning.
- The observation uses the same closed broker data used by ATLAX's analysis.
- Shadow data can be joined to the execution journal before live promotion.
- A live partial/full close or stop action requires a separate decision record.
