# ADR-012: Containment-Aware Routing for Nested CRT Alerts

Status: APPROVED  
Date: 2026-08-14  
Decision owner: Project Lead
Approved by: Project Lead  
Approved date: 2026-08-14

## Context

ATLAX currently preserves CRT events independently across timeframes. The
scanner deduplicates only the same symbol/timeframe/latest-candle combination,
so repeated M15 events formed inside an active M15 range can produce alert noise.
An M5 event inside that range may still be useful when it agrees with the M15
bias.

The approved CRT rulebook currently describes nested events as independent. This
ADR does not change detection. It proposes a documented notification-routing
policy that keeps raw detections auditable while selectively suppressing nested
alerts.

## Decision

ATLAX will:

1. Track the latest active M15 controller per symbol.
2. Treat a candidate as contained when its parent range is inside the controller
   range and its sweep/confirmation closes are inside; child wicks may exceed
   the controller range.
3. Suppress later M15 events contained within that controller range.
4. Allow a contained M5 event only when its CRT classification matches the M15
   controller classification.
5. Suppress a contained M5 event when its classification opposes the M15
   controller classification.
6. Replace the active controller with the latest valid non-contained M15 event,
   whether its bias agrees or opposes the prior controller.
7. Expire a controller only on approved mitigation or invalidation conditions;
   there is no fixed candle-count expiry in V1.
8. Short-circuit suppressed events before strategy and confidence scoring while
   preserving the detector event and routing decision in audit storage.
9. Preserve existing behavior for events outside the controller range.

## Consequences

Positive:

- Reduces repeated same-timeframe consolidation noise.
- Keeps aligned lower-timeframe entries available.
- Makes the suppression reason deterministic and explainable.
- Does not alter CRT detector rules or confidence formulas.

Tradeoffs:

- The routing layer needs persisted controller lifecycle state.
- Alert volume and historical comparisons will change after enforcement.
- The exact mitigation and invalidation expiry behavior must be tested against
  live candle sequences.
- Suppressed events will not have confidence scores or Signal Passport trade
  records unless a separate audit-record schema is introduced.

## Approval Required

The decision is approved for the initial M15 -> M5 implementation. Additional
timeframe relationships require their own configuration review and tests.
