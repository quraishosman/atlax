# ADR-022: Live Profit-Lock Promotion Boundary

Status: Live protective stop tightening enabled; full-close promotion pending  
Date: 2026-09-19  
Owners: ATLAX Engineering

## Decision

ATLAX includes a live-capable protective-stop path for the approved
`TIGHTEN_STOP` action. It is reachable only when the relevant shadow setting is
explicitly disabled after shadow review. The path preserves TP2, refuses to
move an existing stop backward, and treats broker stop-distance rejection as a
failed modification.

`PARTIAL_CLOSE` and `FULL_CLOSE` are not promoted by this decision. They fail
closed in live mode until separately specified, tested, and approved.

The repository is configured with `shadow_mode: false` and
`momentum_shadow_mode: false`. `momentum_action` is `TIGHTEN_STOP`, so live
promotion activates protective stop modifications only. `PARTIAL_CLOSE` and
`FULL_CLOSE` remain fail-closed.

## Consequences

- Explicit shadow configurations can still collect evidence without changing
  trade behavior.
- The live configuration can tighten stops after normalized-R activation and
  giveback, while preserving TP2 and never moving a stop backward.
- Broker-side validation remains authoritative for stop distance and execution.
