# ADR-019: Breakeven Is Triggered By Positive Live Profit

Status: Accepted for Phase 1  
Date: 2026-09-19  
Decision owner: Project lead

## Decision

ATLAX Trade Manager must not use TP1 as the breakeven trigger. When an open
ATLAX position reports positive live broker profit, the manager may move its
stop loss to the actual filled entry price, subject to broker validation.

TP1 partial close remains separate and is permitted only when TP1 is favorable
relative to the actual fill and the position is currently profitable.

## Rationale

Market execution can fill after the planned setup midpoint. A TP1 level that
was valid from the original setup geometry may be behind the actual fill and
must not be treated as a profitable exit. Broker-reported live profit is the
authoritative Phase 1 trigger because it reflects the actual position state.

## Consequences

- Profitable trades can be protected before reaching TP1 or TP2.
- A losing position is never closed merely because price touched an obsolete
  TP1 level.
- Phase 2 MFE locking and Phase 3 momentum-loss exits remain separate proposals
  until their shadow validation is complete.
